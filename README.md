# Vesper Website (Public)

Public website for **Vesper** — 10-foot IPTV player for Android TV.

- **Live site:** https://r766746.github.io/vesper-website/
- **APK Downloads:** via Releases of this repo (public)
- **Private app source:** https://github.com/R766746/NovaIptv (private)

This repo hosts only website + APK releases so private app repo can stay private while Pages works.

## How APKs get here
Private repo `R766746/NovaIptv` builds APKs on tag `v*` and pushes to this repo's Releases via PAT `PUBLIC_REPO_PAT`.

See `PUBLIC_REPO_SETUP.md` in private repo for setup.
