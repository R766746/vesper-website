Privacy • last updated 3 September 2026

Privacy policy

Vesper (package com.nova.iptv) • Contact: vesper_player@proton.me

This is not legal advice. Vesper is a media player. It does not provide, host, sell, or recommend television channels, playlists, or VOD.

Who we are

The publisher of the Android TV app Vesper, application id com.nova.iptv. Contact: vesper_player@proton.me. This site is hosted via GitHub Pages at r766746.github.io/vesper-website.

What stays on your TV

  • Playlist URLs, Xtream usernames, and related settings you enter.
  • The portal password, stored in Android Keystore-backed EncryptedSharedPreferences when the device allows it.
  • M3U stream URLs exactly as you paste them (they may include provider tokens).
  • Parental PIN as a salted hash (a household lock, not strong cryptography).
  • Watch history, favorites, EPG cache, and optional recordings you choose to keep.
  • Optional OpenSubtitles username and API keys you type in Settings.
  • App preferences via Jetpack DataStore.

We do not run an account system. We do not receive your playlists. We do not run analytics in v1.

What leaves the device

Network traffic goes to:

  • Hosts you configure — your IPTV / Xtream / EPG / stream servers, including credentials those URLs contain. If your provider uses HTTP, that traffic is not encrypted (disclosed in Data Safety).
  • Optional metadata services you can leave unused: TMDB, Apple iTunes Search, Wikipedia, TVMaze, OMDb (if you add a key), OpenSubtitles, and YouTube (trailers via official IFrame or YouTube app). Those lookups send titles, TMDB ids, and your IP address to those operators under their policies.

There is no crash reporter in v1. No ads. No in-app purchases.

Website (this GitHub Pages site)

  • This site is static HTML/CSS. No cookies set by us.
  • GitHub Pages may collect logs per GitHub's privacy statement.
  • If you use the feedback form, the contact details, message, device information, and optional attachment you provide are relayed by FormSubmit to the Vesper support email. Do not include playlist credentials, provider tokens, or other sensitive information.
  • The download page fetches api.github.com/repos/R766746/vesper-website/releases/latest client-side to show the latest manually published APK link — that's a request to GitHub's API.

Recordings and backup

Optional recordings and file backups use storage you pick (app-private folder or a SAF folder you grant). In-app backup export omits passwords by default (you can opt-in). Android Auto Backup of the Room library and DataStore is disabled to avoid leaking tokens to Google Drive.

Children

Vesper is a general-audience player. The PIN is a household lock, not a children’s privacy mechanism. No child-directed data collection.

Security

  • Encrypted in transit: HTTPS to TMDB, iTunes, Wikipedia, TVMaze, OMDb, OpenSubtitles, YouTube.
  • Your IPTV hosts may be HTTP — that is controlled by your provider, not Vesper.
  • Keystore-backed vault for passwords where device supports it.

Deletion

Uninstall the app, or delete a playlist in Settings, to remove that library from the device. Recordings in a folder you picked stay until you delete them via file manager. No server copy exists to delete — we don't have your data.

Data Safety (Play Console summary)

No data is collected by the developer; data stored on device is sent to the user-configured provider when playing or importing. Optional third-party sharing for artwork, trailers, and subtitles is listed above.

Changes

We will date this page when the policy changes. Keep using the app only if you accept the current version. For questions: vesper_player@proton.me

Vesper is a player only and does not provide IPTV content. You are responsible for every stream URL you add.
