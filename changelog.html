Changelog

All notable changes to Vesper. APKs are published via GitHub Releases when you push a tag v*. This site auto-links to https://github.com/R766746/NovaIptv/releases/latest.

v1.0.0 — Initial public release

25 August 2026 • versionCode 1 • targetSdk 35
  • Single-activity Compose + androidx.tv + Media3 ExoPlayer + Hilt + Room + DataStore
  • TiviMate-style three-pane Home (categories · groups · channels/posters)
  • Full-screen EPG grid, catch-up / archive, timeshift
  • M3U URL / local file / Xtream Codes import with streaming parser
  • Movies, series, detail, continue watching, favorites, search
  • 2 / 4 / 9 multi-view with PlayerBudget decoder limit (1 fullscreen + 1 preview OR N multi-view)
  • Local PVR: optional recording via SAF folder, one at a time, no transcode
  • Parental PIN (salted hash), backup/restore, four themes (dusk #08070C + champagne gold #C9A36A)
  • First launch is Add Playlist only — no sample streams shipped
  • Privacy: Keystore-backed vault for portal password, no account system, no crash reporter in v1, Android Auto Backup disabled for DB
  • Website: new GitHub Pages site at r766746.github.io/NovaIptv with direct APK download, privacy, terms, changelog
  • CI: GitHub Actions workflows for Pages deploy and APK build+release (auto-build on tag)
Download: github.com/R766746/NovaIptv/releases/latest
Install: adb install -r app-release.apk or via Downloader app on TV.

How versioning works

Continuous
  • Versioning: Semantic — vMAJOR.MINOR.PATCH tags trigger release builds
  • Build: ./gradlew :app:assembleRelease :app:assembleDebug via Actions
  • Signing: If secrets KEYSTORE_BASE64, KEYSTORE_PASSWORD, KEY_ALIAS, KEY_PASSWORD are set, release APK is signed with your keystore. Otherwise CI falls back to debug keystore (installable but you should set secrets for consistent updates)
  • Pages: docs/ folder deployed to GitHub Pages via actions/deploy-pages
  • Next: Play Store listing, optional auto-updater in-app
For maintainers — create a release:
git tag v1.0.0
git push origin v1.0.0
# Actions builds APKs and creates GitHub Release with APKs attached
Or run workflow manually: GitHub → Actions → Build APK and Release → Run workflow.
