Changelog • com.nova.iptv

Changelog

All notable changes to Vesper. Verified APKs are manually published in the public website repository. This site links to https://github.com/R766746/vesper-website/releases/latest.

v1.0.4 — TV Guide and custom XMLTV sources

2 September 2026 • versionCode 4 • targetSdk 35
  • Added a full TV Guide with channel groups, multi-day navigation, programme details, live playback, catch-up, recording, reminders, search, and EPG assignment.
  • Added playlist-scoped custom XMLTV sources from HTTPS URLs or local XML/XML.GZ files, with refresh, enable, disable, and removal controls.
  • Added EPG health and refresh status, richer programme metadata, guide keyboard shortcuts, and player now/next information.
  • Restored focus to the exact programme after returning from fullscreen playback and ordered the main navigation as Live TV, Movies, Series, TV Guide.
  • Clean-built and production-signed from Android repository commit 81bbe79.

v1.0.3 — Phone launcher compatibility

31 August 2026 • versionCode 3 • targetSdk 35
  • Added a standard Android launcher entry so sideloaded Vesper installs appear in phone and tablet app lists.
  • Kept the dedicated Android TV launcher entry and made Leanback hardware optional for broader device compatibility.
  • Added release verification that requires both phone and TV launcher metadata before an APK can be published.
  • Verified installation, launcher resolution, and foreground startup on a Motorola Razr 2025 and Mi TV.
  • Clean-built and production-signed from Android repository commit b6ceb6c.

v1.0.2 — Verified public release

30 August 2026 • versionCode 2 • targetSdk 35
  • Rebuilt from the approved Vesper source on Android repository commit 54c5ebd.
  • Restored production signing and verified the APK and Android App Bundle against the established release certificate.
  • Verified package name com.nova.iptv, version, APK signing schemes, and the published SHA-256 checksum.
  • Improved the release setup to accept quoted Windows keystore paths while keeping credentials outside Git.
  • Replaced the withdrawn download with the correctly branded, tested Vesper release APK.

v1.0.1 — Withdrawn

27 August 2026
  • The APK was built from an older branch and still contained the NOVA branding.
  • Automated publishing from the private source repository has been retired.
  • The next release will be built, signed, verified, and uploaded manually.

v1.0.0 — Initial public release (withdrawn)

25 August 2026 • versionCode 1 • targetSdk 35
  • Single-activity Compose + androidx.tv + Media3 ExoPlayer + Hilt + Room + DataStore
  • three-pane Home (categories · groups · channels/posters)
  • Full-screen EPG grid, catch-up / archive, timeshift
  • M3U URL / local file / Xtream Codes import with streaming parser
  • Movies, series, detail, continue watching, favorites, search
  • 2 / 4 multi-view with a device-aware decoder budget
  • Local PVR: optional recording via SAF folder, one at a time, no transcode

  • Privacy: Keystore-backed vault for portal password, no account system, no crash reporter in v1, Android Auto Backup disabled for DB
  • Website: GitHub Pages site at r766746.github.io/vesper-website with direct APK download, privacy, terms, and changelog
  • Release process: signed APKs are checked and uploaded manually to the public website repository
Download withdrawn. Install only a newer release that passes the verification checklist.

How versioning works

Continuous
  • Versioning: Semantic — vMAJOR.MINOR.PATCH
  • Build: the release APK is built and tested from the approved Vesper source branch
  • Signing: every release uses the same protected production keystore so updates install over earlier versions
  • Pages: the public website repository is deployed through GitHub Pages
  • Next: Play Store listing, optional auto-updater in-app
Release integrity:
The maintainer verifies the app label, version, signature, and SHA-256 checksum before attaching app-release.apk to a public GitHub Release.
