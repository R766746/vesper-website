VESPER

A player. Not a provider.

Package studio.vesper.player · Android TV and phone · current build 1.0.7 (versionCode 7)

What it is. Vesper plays live TV, movies, and series from your M3U, Xtream-compatible, or Stalker/MAG sources. It does not sell, host, or recommend channels.

Privacy policy · Terms of use

Download

Sideload APKs are published on the project website release page (not from this docs mirror alone):

  • github.com/R766746/vesper-website/releases
  • Prefer the latest v1.0.7 (or newer) asset once uploaded; verify the SHA-256 next to the APK.

Play Store listing (when live) uses the same package id. Sideload and Play builds must not be mixed without uninstalling first if signatures differ.

1.0.7 highlights

  • Mobile parental PIN, locked groups, and Settings data confirms (device-verified).
  • Mobile-login QR layout (portrait/landscape) and backup file picker (device-verified).
  • Cast progressive start-grace so a new load is not kept alive by leftover socket activity.
  • TV player options sheet uses a horizontal tab bar (Playback / Picture / Tools).
  • Shared TV rail smooth-snap (BringIntoViewSpec, 28% pivot) on every TvLazy* list.
  • MultiView fails closed when a Stalker portal URL cannot be resolved (no raw CMD fallback).
  • CI uses the GitHub runner Android SDK (no broken legacy tools package).
